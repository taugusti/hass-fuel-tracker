# hass-fuel-tracker

**Fuel Tracker** – a Home Assistant app (add-on) for logging fuel. Take a photo of the pump display and the odometer – Home Assistant's AI Task reads liters, price and odometer reading. Shows km/L, L/100 km, cost per km, distance driven, cost per month/year and more.

## Installation
Settings → Apps → App store → ⋮ → Repositories → add `https://github.com/taugusti/hass-fuel-tracker` → install **Fuel Tracker**.

See [fuel_tracker/DOCS.md](fuel_tracker/DOCS.md).
