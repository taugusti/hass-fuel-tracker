# hass-fuel-tracker

Home Assistant-app (add-on) **Fuel Tracker**: benzinlog for jeeperne. Tag billede af pumpens display og km-tælleren – Claude (HA's AI Task) aflæser liter, pris og kilometerstand. Viser km/L, L/100 km, kr/km, kørte km, udgift pr. måned/år m.m.

## Installation
Indstillinger → Apps → butik → ⋮ → Repositories → tilføj `https://github.com/taugusti/hass-fuel-tracker` → installér **Fuel Tracker**.
